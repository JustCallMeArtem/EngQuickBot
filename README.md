# EngQuickBot — Telegram-бот для вивчення англійської мови

Користувач — людина, яка самостійно вивчає англійську мову; EngQuickBot допомагає регулярно вивчати та повторювати англійські слова й граматику безпосередньо в Telegram, без необхідності встановлювати окремий застосунок і самостійно планувати навчальний процес. Аналоги продукту: Duolingo — окремий застосунок з інтерактивними вправами та системою прогресу, тоді як EngQuickBot працює безпосередньо в Telegram і зосереджується на персональних завданнях та нагадуваннях; Quizlet — сервіс для вивчення наборів карток, тоді як EngQuickBot може автоматично підбирати завдання та організовувати повторення слів; Memrise — платформа з курсами та вправами для вивчення мов, тоді як EngQuickBot пропонує простий формат навчання через Telegram і може адаптувати завдання відповідно до результатів користувача.
